# DaxMac

**Independent Developer Onboarding Audits**

DaxMac is an independent research initiative focused on uncovering documentation-induced onboarding assumptions before they become production failures.

Rather than reviewing documentation for style or completeness, DaxMac examines the mental models documentation creates and how those assumptions affect real-world implementation.

---

## What You'll Find

### Developer Onboarding Audits

Evidence-based audits of API-first products identifying onboarding assumptions that can create production risk.

Current audits include:

- Liveblocks
- Svix

---

### Field Notes

Short research articles exploring recurring documentation patterns observed across developer platforms.

Topics include:

- Documentation relationships
- Initial validation vs. long-term reliability
- Resource lifecycle assumptions

---

## Methodology

Every audit follows the same production-first framework:

1. Review onboarding documentation.
2. Identify the developer assumption.
3. Compare the assumption with production behavior.
4. Explain the business impact.
